## Estrutura

- 21 dias em 3 arcos (Fundamentos · Ecossistema · Autonomia)
- 1 desenho por dia em assets/desenhos/
- Mesmos marcos: 7 = bronze, 14 = prata, 21 = ouro (mesmo engine de badges)
- Sala: categoria ACADEMY no Discord MintPass Lab

## O sanduíche narrativo

- Dia 1: a promessa (história do Bob + bússola dos 4 pilares)
- Dias 2-7: a base (wallet, transação, blocos, consenso, testnet, explorer)
- Dia 8: a retomada ("lembra da bússola? agora destrava")
- Dias 9-14: o ecossistema (stablecoins, DEX, lending, NFTs, DAOs, redes)
- Dias 15-21: autonomia (segurança, leitura de contratos, primeiro token)
- Dia 13: o loop do Bob se fecha (ele vira dono)
- Dia 21: graduação com endereço, transações e token próprios

## Regras do método

- Toda aula tem: o que faz / como faz / passos / saída esperada /
  erro de iniciante / prova
- Toda aula de ecossistema termina com disclaimer educacional
- Toda fonte externa é citada em docs/academy/leituras.md
- Desenho novo por dia: uma metáfora visual, nunca um print técnico
